Keeps a to-do list, one task per line, in the file todo.txt in the current directory, driven by the command line. "add" followed by words appends the words joined by spaces as one task; "done" followed by a number removes the task at that 1-based position; "show" lists the tasks; anything else, including a missing, non-numeric or non-positive number, prints "usage: todo add <task> | todo done <number> | todo show". After add or done the file is saved and the numbered list is printed as "1. <task>" lines; show prints the list. A missing or unreadable file counts as an empty list. It needs the console, the environment and the filesystem. It fails with a file error when saving fails.
