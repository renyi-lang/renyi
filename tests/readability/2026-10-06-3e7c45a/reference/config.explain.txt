A library (no entry point) that loads and validates a service configuration from a JSON file: a port from 1 to 65535, a worker count from 1 to 64 and a log level of Quiet, Normal or Verbose. Loading fails with Unreadable (with the path) when the file cannot be read and with Invalid (with a detail text) when the JSON does not match that shape. The default configuration is port 8080, 4 workers and Normal. One function loads the file and falls back to a configuration the caller supplies when loading fails; an older function that falls back to the defaults is deprecated since version 0.2 in favour of it. The loading functions need read access to the filesystem.
