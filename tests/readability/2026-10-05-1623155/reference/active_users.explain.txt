Reads the JSON file data/users.json (a fixed path), decodes it as a list of users (name, age of at least 0, active flag, e-mail matching a basic address pattern), keeps the active users aged at least 18, sorts them by name, prints each e-mail address on its own line and then prints "<count> active adults". The reusable function takes the file path and returns the e-mail addresses. It needs the console and read access to the filesystem. It fails with a file error when the file cannot be read and with a JSON error when the text does not decode into the user shape (a negative age or an implausible e-mail address included).
