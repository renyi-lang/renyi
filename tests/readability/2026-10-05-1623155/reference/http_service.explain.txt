A small JSON API that converts temperatures. It prints "listening on http://localhost:8080" and serves on port 8080 until the process is stopped. The path /health answers the text "ok"; /convert reads the query parameter celsius and answers JSON with both the Celsius value and the Fahrenheit value (celsius times 9 over 5 plus 32); a missing parameter answers a bad request "celsius is required" and a non-numeric one a bad request "celsius must be a number"; any other path answers not found. It needs the console and socket network access. It fails with a start error when the server cannot start.
