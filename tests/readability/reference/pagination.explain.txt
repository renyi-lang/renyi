Fetches every page of a cursor-paginated API and counts customers per country. Fetching all starts at the base URL and, while a page carries a next cursor, requests the base URL with "?cursor=<token>", collecting the customers (id, name, country) of every page. The entry point fetches https://api.example.com/customers, groups the customers by country and prints "<country>: <count>" with the largest count first. It needs the console and HTTP network access. It fails with an HTTP error when a request fails and with a JSON error when a page does not decode.
