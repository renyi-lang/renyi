Sends one question to a chat-completion HTTP API and prints the model's answer. The question is the command-line arguments joined by spaces; the API key is read from the environment variable CHAT_API_KEY. It posts a JSON request (model "example-model", one user message) with a bearer authorization header to a fixed endpoint, decodes the JSON response and takes the text of the first choice. The reusable function takes the question and the key and returns the answer text. It needs the console, the environment and HTTP network access. It fails with MissingApiKey when the variable is absent, NoAnswer when the response holds no choices, and Transport with the error text when the HTTP call or the JSON decoding fails.
