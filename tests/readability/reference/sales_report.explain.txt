Summarizes a CSV of sales by region and writes the totals to a report file. It reads data/sales.csv and validates every row: region, product and a numeric amount; the first bad row fails with BadRow (line number and detail), and an unreadable file or invalid CSV fails with Io (detail). It sums the amounts per region, prints "<region>: <amount>" from the largest total to the smallest, and writes the same totals as CSV with the header line "region,total" to data/report.csv (a write failure is Io). It needs the console and the filesystem restricted to the data directory.
