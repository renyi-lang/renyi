Counts how often each word appears in a text file and shows the ten most common. Counting lower-cases the words, splits each line on single spaces, ignores empty pieces and keeps punctuation attached to words; the result lists each word with its number of occurrences, most frequent first. The entry point reads the file named by the first command-line argument, or data/sample.txt when there is none, and prints the ten most frequent words as the count right-aligned in 6 characters, two spaces, and the word. It needs the console, the environment and read access to the filesystem. It fails with a file error when the file cannot be read.
