A library (no entry point) with one function that retries a failing action with exponential backoff and jitter: it runs the action up to the given number of attempts and returns the first success. After each failure it records "attempt <n>: <error text>", sleeps for the current delay plus a random jitter of up to a quarter of it, and doubles the delay; the delay starts at 100 milliseconds, and the sleep also happens after the last failed attempt. When every attempt fails it fails with GaveUp, carrying the number of attempts and the last error text only. It needs the clock (for sleeping) and random numbers.
