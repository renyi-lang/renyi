Shows the current temperature and wind speed for Berlin from the Open-Meteo API. Fetching a forecast requests api.open-meteo.com/v1/forecast for a latitude and longitude with the current temperature and wind speed and decodes the JSON. The entry point fetches the forecast for 52.52, 13.41 and prints "Berlin: <temperature> C, wind <speed> km/h". It needs the console and HTTP network access (the fetch restricted to api.open-meteo.com). It fails with Unreachable (detail) when the HTTP request fails and BadResponse (detail) when the response does not decode.
