A library (no entry point) with one function, published to agents as a tool: convert an amount from a source currency to a target currency (three-letter upper-case ISO codes) at today's rate, rounded to cents. It fetches the rate from api.frankfurter.app (the latest endpoint with the two currencies) and decodes the JSON rate table. It needs HTTP network access restricted to that host. It fails with RateUnavailable (source and target) when the response holds no rate for the target, with an HTTP error when the request fails and with a JSON error when the response does not decode.
