It offers an immutable, generic last-in-first-out stack where pushing returns a new stack with the item on top, popping returns the top item plus the remaining stack (or nothing if the stack is empty), peeking shows the top without removing it, and a public size ability reports how many items a stack holds and whether it is empty. Built on that stack is a bracket checker that answers true or false for whether every round and square bracket in a text is closed by its matching partner in the right nested order, so a stray closer, a mismatched pair or an unclosed opener gives false while text without brackets gives true. It is self-contained, pure in-memory code that needs no permissions and is backed by examples and two tests, so it suits simple stack needs or quick checks of parentheses and square brackets, but it ignores curly braces and every other character and returns only true or false without saying where a mismatch is.
