This program prints a small Celsius-to-Fahrenheit conversion table to the console: a header line, then one row for each of -10, 0, 10, 20, 30 and 40 degrees Celsius (both ends of the range are included) next to the matching Fahrenheit value, 14 up to 104, with each number right-aligned under its column heading. The conversion itself is a separate public function that takes a decimal Celsius value and returns Fahrenheit by multiplying by nine fifths and adding 32, so you can reuse it from other code, and it is documented with examples for 0, 100 and -40 degrees. The program reads no input and only needs permission to print to the console, with no file or network access, but the range and step are fixed in the source, so it suits a quick fixed demo table and would need editing for any other range.
