This program provides a single tool, published for agents to call, that converts an amount from one currency to another using the latest exchange rate fetched live from the external Frankfurter web service, rounding the result to two decimal places (cents). Callers supply the amount plus the source and target currencies as three-letter upper-case codes, and the tool may use the network only to reach that one service, with no file, console or other access. Because it depends on that service being reachable, it fails with an error if the web request fails, if the reply is not the expected JSON, or if the service has no rate for the requested currency pair.
