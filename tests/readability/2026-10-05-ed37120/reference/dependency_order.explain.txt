Orders build steps so that every step runs after the steps it depends on: given a map from step to its dependencies, it returns a topological order in which ties are broken alphabetically (in every round, every step whose dependencies are already placed is appended in alphabetical order). It fails with UnknownDependency (step and dependency) when a dependency is not a step of the map, and with Cycle (the remaining steps, sorted) when no step can be placed. The entry point orders a sample project (package needs test and docs, test and docs need build, build needs fetch) and prints "1. fetch", "2. build", "3. docs", "4. test", "5. package". It needs the console; an ordering error ends the program.
