Prints a directory tree with the size in bytes of every file and folder. The size of a path is the file's size, or the sum of the sizes of everything under a directory (other kinds of entry count as 0). Each entry prints as "<name> (<size> bytes)" indented by two spaces per level, and a directory's children follow one level deeper, sorted by name. The entry point takes the root directory from the first command-line argument, or the current directory when there is none. It needs the console, the environment and read access to the filesystem. It fails with a file error when an entry cannot be inspected or listed.
