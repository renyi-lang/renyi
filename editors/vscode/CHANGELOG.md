# Changelog

## 0.3.0

The binary's release 0.3.0 (the C API and its Python binding); the
extension is unchanged.

## 0.2.1

The binary's release 0.2.1; the extension is unchanged.

## 0.2.0

The language client (decision AN2): the extension starts `renyi lsp` for
the workspace folder and shows its diagnostics, hover, go to definition,
find all references, rename (decision AW38 for declarations, AW39 for
variables), completion, signature help and workspace symbols (decision
AW44) and the outline; the setting `renyi.path` names the binary.

## 0.1.0

The first release: the TextMate grammar of the language reference
(comments, clauses, text, numbers, the reserved words and phrases,
capabilities, types, calls) and the language configuration (comments,
brackets, indentation around `end`).
